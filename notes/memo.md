# GIT 학습 메모

## 오늘의 목표

- 현재 폴더를 확인한다.
- 파일을 작성하고 저장한다.
- 변경 이유를 기록한다.

## 오늘 배운 내용 정리

- 전체 흐름
git init 으로 로컬 리파지토리 만들고
stataus로 상태 확인
add로 스테이지에 올리고
commit으로 이력을 기록한 후
log로 기록을 확인한다.

- -m으로 제목과 본문 작성
